SchedulerAI

AI-Powered Meeting Scheduler  ·  Product Overview for Management  ·  v2.0

✦ Production Ready

SchedulerAI lets you schedule meetings using plain English. It connects with Google Calendar, Microsoft Outlook, Zoom, and Microsoft Teams — extracts meeting details with AI, detects conflicts, and sends invites in under 30 seconds. Admins control which integrations are enabled; users manage their own connected accounts and preferences.

Current Features
🤖 AI Extraction 📅 Google Calendar 📅 Outlook Calendar 🎥 Google Meet 💼 Microsoft Teams 🎬 Zoom 🔐 Google OAuth 🔐 Microsoft OAuth ⚡ Conflict Detection 🚨 Priority Badges ⚙️ Admin Panel 👤 User Settings 🔄 Multi-AI Providers 🕒 Timezone Support
🤖 Natural Language Scheduling
Type raw meeting notes like "Budget review with John tomorrow 3 PM for 1 hour." AI (Groq / GPT-4o / Claude / Gemini) extracts title, participants, date, time, and duration with no forms required.
📅 Multi-Calendar Integration
Google Calendar and Microsoft Outlook are both live. Real-time busy slot checking via OAuth — if your chosen time is taken, the nearest available alternatives are suggested automatically.
🎥 Multi-Platform Meeting Links
Google Meet links auto-generate via Google Calendar. Zoom uses Server-to-Server OAuth. Microsoft Teams creates online meetings via Graph API and adds them to Outlook Calendar. User picks the platform before booking.
⚡ Smart Conflict Detection
If the requested slot overlaps with existing events, the system offers up to 3 alternative time slots ranked by proximity. No manual back-and-forth needed.
⚙️ Admin Settings Panel
Administrators toggle calendar providers, meeting platforms, and auth providers on or off via a dashboard. Settings persist in MongoDB (ProviderSettings model) and propagate to all users instantly.
👤 User Settings & Preferences
Each user configures their timezone (23 zones), default meeting duration presets, and manages their connected calendar + meeting accounts. Preferences are stored per-user in MongoDB.
🚨 Priority & Urgency Detection
Detects keywords like "urgent," "critical," or "ASAP" and assigns a High / Medium / Low priority badge to each meeting automatically, surfaced in the dashboard agenda view.
📋 Conversational Missing-Field Recovery
If any required detail is missing (no email, no time), the system asks one targeted follow-up question at a time — keeping UX conversational rather than showing a big form.

Admin Panel & User Settings
⚙️ Admin Settings Panel
  • Toggle each calendar provider, meeting platform, and auth provider on/off
  • Settings stored in MongoDB ProviderSettings collection
  • Seeded with defaults on server startup via AdminController
  • Integration status reflects immediately for all users
  • Admin-only route protection with role check
  • Live status indicators per provider (Live / Disabled)
👤 User Settings Page
  • 23 timezone options (UTC−12 through UTC+14)
  • Default meeting duration presets (15 / 30 / 45 / 60 / 90 min)
  • Connected integrations manager — connect or disconnect Google, Microsoft, Zoom per-account
  • Preferences persisted per-user in MongoDB User model
  • View currently linked calendar and meeting accounts
Integration Service Architecture: A dynamic provider registry (providerRegistry.js) + IntegrationService.js resolve which providers are available at runtime — combining the static available flag, the per-user OAuth token presence, and the admin-toggled MongoDB state. No code changes needed to add new providers; register in the registry only.
